# CELLTRONIC ERP & CRM

Sistema integral de gestión empresarial diseñado para la administración de tiendas de tecnología, venta de accesorios y talleres de servicio técnico.

## 🚀 Tecnologías utilizadas

* **Frontend:** React / Vite / TypeScript
* **Estilos:** Tailwind CSS / Lucide React
* **Backend & Base de datos:** Firebase (Firestore)
